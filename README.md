## Run Locally

**Requirements:** Node.js 22 or newer.

```bash
npm install --legacy-peer-deps
npm run dev
```

To create a production build:

```bash
npm run build
```

## Deployment

A GitHub Actions workflow builds and publishes this site to GitHub Pages whenever changes are pushed to `main`.
